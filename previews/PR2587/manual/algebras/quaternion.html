Quaternion algebras ​

We provide a model for quaternion algebras over a field K in standard form, which is parametrized by two elements a,b∈K. The corresponding quaternion algebra has a basis 1,i,j,k satisfying i2=a, j2=b and ij=−ji=k.

This functionality is currently restricted to fields of characteristic not equal to two.

Creation ​

quaternion_algebra Method
julia
quaternion_algebra(K::Field, a, b) -> QuaternionAlgebra

If the characteristic of K isn't 2, return the quaternion algebra (a,b)K defined by i2=a, j2=b, and ij=−ji.

If the characteristic of K is 2, return the quaternion algebra [a,b)K defined by i2+i=a, j2=b, and ij=ji+j.

Examples

julia
julia> Q = quaternion_algebra(QQ, -1, -1)
Quaternion algebra
  over rational field
  defined by i^2 = -1, j^2 = -1, ij = -ji

julia> K, sqrt2 = quadratic_field(2);

julia> Q = quaternion_algebra(K, sqrt2, -1)
Quaternion algebra
  over real quadratic field defined by x^2 - 2
  defined by i^2 = sqrt(2), j^2 = -1, ij = -ji

julia> R, x = polynomial_ring(GF(2), "x"); F=fraction_field(R);

julia> Q = quaternion_algebra(F, 0, x)
Quaternion algebra
  over fraction field of R
  defined by i^2 = i+0, j^2 = x, ij = ji+j

quaternion_algebra_ramified_at Method
julia
quaternion_algebra_ramified_at(K::QQField, p::IntegerUnion;
                               check::Bool = true)
  -> QuaternionAlgebra{QQFieldElem}

Return the quaternion algebra over Q that is ramified exactly at the prime p and at infinity, presented as (−p,−q)Q, so i2=−p and j2=−q, where q is the least prime with q≡3mod8 and (pq)=−1.

The algebra carries the maximal order, which maximal_order returns,

Z+Z1+j2+Zi(1+j)2+Z(r+i)jq,

where r is the square root of −p modulo q in (0,q/2]. Both q and r are determined by p, so the algebra and its maximal order are the same on every call.

If check is true, it is tested that p is prime.

The presentation and the order are those of [1], Lemmas 1.1 and 1.2, with the least admissible q, which exists by Dirichlet's theorem.

Examples

julia
julia> A = quaternion_algebra_ramified_at(QQ, 97)
Quaternion algebra
  over rational field
  defined by i^2 = -97, j^2 = -19, ij = -ji

julia> abs(discriminant(maximal_order(A))) == 97^2
true

eichler_level Method
julia
eichler_level(O::AlgAssAbsOrd{<:QuaternionAlgebra}) -> ZZRingElem
eichler_level(O::AlgAssRelOrd{<:Any, <:Any, <:QuaternionAlgebra})
  -> AbsNumFieldOrderIdeal

Return the level of the Eichler order O of a quaternion algebra A over K: the ideal M of the ring of integers of K, coprime to the discriminant D of A, with discrd(O)=DM [2], 23.4.19. Over Q it is returned as a positive integer.

An ArgumentError is thrown if O is not an Eichler order, see is_eichler.

Examples

The order of the matrices (ab6cd), with a,b,c,d∈Z, in M2(Q)≅(1,1)Q, spanned by the matrix units (1±i)/2, (j+k)/2 and 6 times (j−k)/2:

julia
julia> A = quaternion_algebra(QQ, 1, 1);

julia> e, i, j, k = basis(A);

julia> h = QQ(1, 2);

julia> O = order(A, [h * (e + i), h * (e - i), h * (j + k), 3 * (j - k)]);

julia> eichler_level(O)
6

julia> eichler_level(maximal_order(A))
1

Right ideal classes and types ​

right_class_set Method
julia
right_class_set(O::Union{AlgAssAbsOrd, AlgAssRelOrd}) -> Vector

Return representatives of the classes of locally principal right ideals of the order O of a quaternion algebra A over Q or a number field. Two ideals I and J lie in the same class if J=αI for some α∈A×.

The representatives are integral right ideals of O.

Examples

julia
julia> O = maximal_order(quaternion_algebra_ramified_at(QQ, 97));

julia> C = right_class_set(O);

julia> length(C), all(I -> right_order(I) == O, C)
(8, true)

julia> length(right_class_set(maximal_order(quaternion_algebra(QQ, -1, 3))))
1

Gross lattices ​

gross_lattice Method
julia
gross_lattice(O::AlgAssAbsOrd{<:QuaternionAlgebra{QQFieldElem}}) -> ZZLat

Return the Gross lattice of an order O of Bp, the quaternion algebra over Q ramified exactly at a prime p and infinity: the image of O under x↦2x−trd(x), which is the set of elements of reduced trace zero in Z+2O [3, 4]. It is a positive definite lattice of rank 3, with the reduced norm as its quadratic form. The order need not be maximal; an ArgumentError is thrown if the algebra of O is not of the form Bp.

It lies in the quadratic space on the coordinates with respect to basis(A) whose bilinear form is (x,y)↦trd(xy¯)/2, so that the norm of a vector is the reduced norm of the element and not twice it. Its basis consists of the coordinates of gross_lattice_basis and its Gram matrix is gross_gram_matrix of that basis.

For a maximal order of Bp, the determinant of the Gram matrix is 4p2 [3], and two maximal orders of Bp are isomorphic if and only if their Gross lattices are isometric [4].

Examples

julia
julia> A = quaternion_algebra(QQ, -1, -3);

julia> L = gross_lattice(maximal_order(A));

julia> rank(L), det(L)
(3, 36)

gross_gram_matrix Method
julia
gross_gram_matrix(B::Vector{<:AssociativeAlgebraElem{QQFieldElem}})
  -> ZZMatrix

Return the Gram matrix of the three elements in B, a basis of a Gross lattice of an order of Bp (see gross_lattice), with respect to the bilinear form (x,y)↦trd(xy¯)/2: the reduced norms of the elements are on its diagonal. The matrix is integral for a basis of a Gross lattice; an ArgumentError is thrown otherwise.

Examples

julia
julia> A = quaternion_algebra(QQ, -1, -3);

julia> B = gross_lattice_basis(maximal_order(A));

julia> G = gross_gram_matrix(B);

julia> det(G), [G[i, i] for i in 1:3] == normred.(B)
(36, true)
